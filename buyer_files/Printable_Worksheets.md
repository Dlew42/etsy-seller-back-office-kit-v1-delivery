## Listing checklist

- [ ] Title uses clear buyer/search phrase.
- [ ] 13 tags drafted, each under 20 characters.
- [ ] Description says what is included and how delivery works.
- [ ] No sales/profit/ranking guarantee.
- [ ] Digital download only is clear.
- [ ] Files are named clearly.
- [ ] Files are under Etsy limits: up to 5 files, max 20MB each.
- [ ] Images explain the product without relying on tiny text.
- [ ] Unofficial-resource disclaimer included if using platform name.
